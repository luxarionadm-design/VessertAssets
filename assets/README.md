# VessertID Asset Repository & Design System

Welcome to the official asset repository for the **VessertID** platform. This directory contains all multimedia, legal, marketing, user interface, 3D models, shaders, audio sound effects, and localization files for the modern spatial 3D platform.

## Directory Structure
- `legal/`: Terms of Service, Global Privacy Policies (GDPR, CCPA, PDP), Cookie Policy, Community Guidelines, and Licensing.
- `brand/`: Vector and bitmap logos, Brand Identity Guidelines, Multi-platform App Icons (iOS, Android, Web, Watch), Store listings, and Press Kit.
- `marketing/`: Multi-channel Advertising Campaigns (Meta, TikTok, YouTube, X, Google Ads), Landing assets, and Partner collateral.
- `onboarding/`: Welcome vectors, User Flows, Interactive Tutorials, Tooltips, Empty States, and Permission prompts.
- `email/`: Responsive HTML & plain text transactional, notification, security, marketing, and billing email templates.
- `moderation/`: Content Sensitivity Labels, Age Gate Overlays, Reporting Reason schemas, and Account Suspension screens.
- `monetization/`: Pricing Tiers, Subscription Badges, Official Payment Method vectors, and Virtual Gift catalogs.
- `ui/`: Full SVG Icon library (Navigation, Actions, Social, Player, Media, Communication, Security, Status, Arrows), Error & Feature Illustrations, and Theme tokens.
- `content/`: High-resolution Media Samples (Avatars, Posts, HLS Video Streams, Audio Tracks, Lottie Animated Stickers).
- `data/`: Comprehensive JSON datasets for feeds, user profiles, comments, direct messages, stories, reels, and live streams.
- `schemas/`: Official JSON Schemas for validating data entity structures.
- `i18n/`: Comprehensive internationalization dictionaries across 18 languages.
- `fonts/`: Modern web font families in multiple weights (Inter, JetBrains Mono, Noto Sans regional).
- `shaders/`: Production-grade WebGL/WebGPU GLSL shader modules (Post-processing blur, vignette, grain, chromatic aberration, AR face warp).
- `models/`: Binary glTF 2.0 3D models (.glb) for avatars, face meshes, hand meshes, and AR occluders.
- `sfx/`: Interactive UI, notification, call, and recording audio sound effects in MP3 format.
- `support/`: Help Center articles, FAQ, Chatbot dialog flows, and Bug Report templates.
- `security-badges/`: Certified Security Seals (SSL, ISO 27001, GDPR, PCI-DSS Level 1).
- `analytics/`: Vector Analytics Charts, Dashboard schemas, and Export templates.
